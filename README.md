# C++ Task Management System

A console-based task management application developed using C++.  
This project focuses on building strong core logic, clean structure, and proper user interaction through the terminal.

---

## Features
- User registration and login with basic validations
- Task creation with simple and readable task IDs (T1, T2, ...)
- Task status management:
  - Pending tasks
  - Completed tasks
  - Deleted tasks
- Filtering tasks by status (All / Pending / Completed)
- Prevents completing or deleting already completed tasks
- Clear and user-friendly console output
- Proper logout confirmation message.

---

## Concepts Used
- C++ functions and modular programming
- Conditional statements and loops
- Vectors and basic STL usage
- Input validation and edge case handling
- File organization and readable code structure

---

## How the Application Works
1. User registers with valid name, email, and password
2. User logs in using registered credentials
3. User can:
   - Add new tasks
   - View all tasks
   - Mark pending tasks as completed
   - Delete pending tasks only
   - Filter tasks by status
4. Completed tasks cannot be modified again
5. User logs out safely with confirmation message
